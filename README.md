**Waar staat de afkorting voor?**

*WWW staat voor world wide web*
**Definitie**

1. Leg het concept uit in je eigen woorden

- *WWW staat voor world wide web, de www is een systeem dat webpaginas en documenten met elkaar laat verbinden die je via het internet kan bekijken*


2. Hoe draagt x bij aan de functionaliteit van het internet?

- *de www vormt de gebruiksvriendelijke interface en de informatielaag van de internet. het voegde ook integratie van multimedia op en de toegankelijkheid via hyperlinks.*

**Veiligheid**

3. Welke rol speelt x bij het waarborgen van de beveiliging van online communicatie?

- *de www speelt geen rol in de beveiliging van online communicatie, als je een beveiligde website wil moet je gebruik maken van https*


4. Welke data zou gestolen kunnen worden wanneer een hacker toegang krijgt tot dit protocol?

- *een hacker kan alles stelen wat er beschikbaar is, dus je inloggegevens, bankgegevens, persoonlijke gegevens,...*

5. Hoe vergemakkelijkt het WWW de uitwisseling van informatie op het internet?

- *de www doet het door een visuele  gebruiksvriendelijke laag bovenop de internet te leggen. alle informatie wordt verzamelt in fysieke kabels*


6. Hoe heeft de opkomst van het WWW de manier waarop informatie wordt gedeeld en geconsumeerd veranderd?


- *de informatie kan je binnen 1 second vinden op de internet ipv op kranten of artikels waar er beperkte informatie staat. Het nieuw nieuws duurt niet meer dagen voordat het wordt gereleased maar het wordt live gebroadcast. We kunnen ook informatie van het verleden makkelijk terug vinden maar als je alleen maar toen artikels en kranten had kon dat niet.*
